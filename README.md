#### Description:
TaskFlow – Task Management Website

TaskFlow is a modern, user-friendly task management website designed to help users organize and manage their daily tasks efficiently. The website provides a simple command-based system that allows users to add, update, delete, and view tasks by entering a specific number. Users can type **1 to add a task, 2 to update a task, 3 to delete a task, and 4 to display all tasks** in a table structure. An Exit button is also available to end the current session view.

The website features a clean and attractive interface with a purple color theme, organized sections, and a structured task table. The table headings remain visible at all times, while the task details are displayed only when the user selects the Show Tasks option. Each task is assigned a unique ID, making it easier to update or delete specific tasks. The website also uses browser local storage to save tasks, allowing users to access their saved tasks again when they reopen the website in the same browser.

TaskFlow is built using **HTML, CSS, and JavaScript**, making it lightweight, responsive, and easy to use without requiring any additional software installation. Its main purpose is to demonstrate basic task management operations, user interaction, and dynamic table updates through a simple and visually appealing website.

## Run it
1. Download a ZIP file Form My GitHub Account.
2. Extract the zip file
3. Keep `index.html`, `style.css`, and `script.js` in the same folder.
4. Double-click `index.html` to open it in a modern browser.

No installation or server is required.

## Commands
- `1` — Add a task
- `2` — Update a task (enter the task ID, then the new description)
- `3` — Delete a task (enter the task ID)
- `4` — Show tasks in the table
- **Exit** — Ends the current session view; use “Back to TaskFlow” to continue.

Tasks are saved in the browser's local storage. The table header is always visible, while task rows remain hidden until command 4 is selected. After adding/updating/deleting, run command 4 to see the refreshed table.
