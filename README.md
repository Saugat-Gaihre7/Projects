#### Description:
 responsive task-management website built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file (if downloaded as a ZIP).
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Double-click `index.html` to open it in a modern browser.

No installation or server is required.

## Commands
- `1` — Add a task
- `2` — Update a task (enter the task ID, then the new description)
- `3` — Delete a task (enter the task ID)
- `4` — Show tasks in the table
- **Exit** — Ends the current session view; use “Back to TaskFlow” to continue.

Tasks are saved in the browser's local storage. The table header is always visible, while task rows remain hidden until command 4 is selected. After adding/updating/deleting, run command 4 to see the refreshed table.
